# 🧠 О проекте
DVI-Joke — это студенческий проект, созданный участниками Новосибирского государственного университета (НГУ), направленный на разработку собственной системы микропроцессорного зажигания.
Проект разработан с использованием фреймворка esp-idf, в качестве платформы используется esp32-c6 super mini
# 🚀 Цели проекта
Разработка низкоуровневого кода для esp
Обучение и развитие навыков работы в команде
Подготовка к реальным вызовам в сфере кибербезопасности
# 👥 Участники
Проект разрабатывается студентами НГУ.
Мы всегда открыты к новым идеям, предложениям и участникам!
